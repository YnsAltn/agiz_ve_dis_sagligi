AĞIZ VE DİŞ SAĞLIĞI WEB SİTESİ

İçerik (hepsi aynı dizinde):
- index.html
- style.css
- konu-1.png ... konu-5.png  (5 bilgilendirme görseli)
- dis-fircalama.mp4
- video-kapak.jpg

Kullanım:
1. Bu klasördeki TÜM dosyaları bir yere kopyalayın.
2. index.html dosyasını tarayıcıda açın.

ÜCRETSİZ YAYINLAMA (GitHub Pages)
1. GitHub'da yeni bir repository oluşturun.
2. Bu klasörün içindeki tüm dosyaları repository ana dizinine yükleyin.
3. Settings > Pages > Deploy from a branch > main / (root) seçip Save'e basın.
