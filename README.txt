AĞIZ VE DİŞ SAĞLIĞI WEB SİTESİ

İçerik:
- index.html: Ana sayfa ve PDF'deki tüm konu metinleri
- style.css: Tasarım ve mobil uyumluluk
- images/: PDF'deki beş bilgilendirme şemasının görsel alanları
- dis-fircalama.mp4: Sayfada oynatılabilen video
- video-kapak.jpg: Video kapak görseli

ÜCRETSİZ YAYINLAMA (GitHub Pages)
1. GitHub'da yeni bir repository oluşturun.
2. Bu klasörün içindeki tüm dosya ve klasörleri (index.html, style.css, images klasörü, video dosyası vb.) repository ana dizinine yükleyin.
3. Repository > Settings > Pages bölümünü açın.
4. Build and deployment altında Deploy from a branch seçin.
5. Branch olarak main, klasör olarak /(root) seçip Save'e basın.
6. Birkaç dakika sonra GitHub Pages adresiniz oluşur.

ÖNEMLİ:
- index.html, style.css, video-kapak.jpg, dis-fircalama.mp4 ve images klasörü aynı proje dizininde bulunmalıdır.
- Video dosyası yaklaşık 6,5 MB'tır. GitHub Pages'e yüklerken video dosyasını da ekleyin.
- QR kodu, yayınlanan GitHub Pages adresine yönlendirecek şekilde oluşturabilirsiniz.
